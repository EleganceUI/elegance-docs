The examples live in the [elegance-examples](https://github.com/EleganceUI/elegance-examples)
repository, one folder each, in C++ (`<name>-cpp`) and Rust (`<name>-rs`). Each folder is a
complete project with its own build files, so you can copy one to start an app. Where an example
has a Rust version, the language switch shows it.

<Lang only="cpp">

```sh
cd elegance-examples/todos-cpp
cmake --preset macos-release      # or windows-release
cmake --build build/macos-release
```

The app is built into `build/<preset>`. On Linux, configure without a preset, as in
[Installation](../start/installation/).

</Lang>

<Lang only="rust">

```sh
cd elegance-examples/todos-rs
cargo run --release
```

</Lang>

## minimal

The smallest app: one window, an icon and two lines of text.

<Example name="minimal" />

## counter

State and reactive arguments. Writing the count updates exactly the views that read it. See
[State and data flow](../guides/state/).

<Example name="counter" />

## todos

A list in state: a text field, `ForEach` keyed by id, `If`, a computed count, and animated
insertions and removals. The [first app tutorial](../start/first-app/) builds it step by step.

<Example name="todos" collapsed />

## layout

Stacks, spacers, frames, overlays, and a custom flow layout for the tags. See
[Layout](../guides/layout/) and [Custom layouts](../guides/custom-layouts/).

<Example name="layout" collapsed />

## styling

A custom theme, light and dark mode, a button style, a view modifier, and a custom environment
value. See [Colors and themes](../guides/themes/) and [Control styles](../guides/styles/).

<Example name="styling" collapsed />

## drawing

Gradients, dashed strokes, an SVG path, a shape computed from its frame, and a chart drawn in a
`Canvas`. See [Shapes and drawing](../guides/drawing/).

<Example name="drawing" collapsed />

## animation

A banner with a transition, a switch with an implicit spring, and tiles that slide to their new
places when shuffled. See [Animation](../guides/animation/).

<Example name="animation" collapsed />

## title-bar

A window without the system frame: its own title bar, window controls, and a translucent, rounded
panel. See [Windows](../guides/windows/).

<Example name="title-bar" collapsed />

## media-player

Open a video with the file dialog, or drop one on the window, and play it with the built-in
controls. See [Video](../guides/video/).

<Example name="media-player" collapsed />

## network

HTTP with cpp-httplib on a background thread, and a long, lazily built list of images from the
web. See [Networking](../guides/networking/).

<Example name="network" collapsed />

## recorder

Voice memos with a live level meter, and a camera preview with snapshots. See
[Microphone and camera](../guides/capture/).

<Example name="recorder" collapsed />

## desktop

File dialogs, notifications, a tray icon with a menu, and dropping files from other apps. See
[Desktop integration](../guides/desktop/).

<Example name="desktop" collapsed />

## More

elegance-examples also has:

- larger apps: `login-cpp`, a sign-in screen with a QR code, and `music-cpp`, `shell-cpp`, and
  `design-cpp`;
- a starter app split into components: `hello-cpp` and `hello-rs`;
- [hot reload and previews](../guides/hot-reload/), set up and ready: `preview-cpp` and
  `preview-rs`;
- more on one topic each: `effects`, `grids`, and `popover`, in both languages, and `fonts-cpp`,
  `navigation-cpp`, and `spinner-cpp`;
- Rust only: `components-rs` (every kind of [component prop](../guides/custom-views/#components),
  children, and modifiers of your own), `split-view-rs`, `icon-strip-rs`, and `wgpu-image-rs` and
  `wgpu-direct-rs`, which draw with [wgpu](https://wgpu.rs) into an Elegance window.
