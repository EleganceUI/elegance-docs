<section class="elg-home-section">
	<p class="elg-home-kicker">Why Elegance</p>
	<h2 class="elg-home-heading">Everything you need for a real app, nothing you don't.</h2>
	<div class="elg-features">
		<div class="elg-feature">
			<span class="elg-feature-icon"><Icon name="puzzle" size="1.25rem" /></span>
			<h3>Views are values</h3>
			<p>Build screens from stacks, text, and controls, then refine them with modifiers like `.padding()` and `.background()`. Appearance lives next to structure, in the language you already write.</p>
		</div>
		<div class="elg-feature">
			<span class="elg-feature-icon"><Icon name="rocket" size="1.25rem" /></span>
			<h3>Precise updates</h3>
			<p>Read state in a closure and that closure re-runs when the state changes. Nothing is diffed and nothing is rebuilt: only the text, color, or frame that depends on it updates.</p>
		</div>
		<div class="elg-feature">
			<span class="elg-feature-icon"><Icon name="laptop" size="1.25rem" /></span>
			<h3>Drawn on the GPU</h3>
			<p>A WebGPU renderer with anti-aliased shapes, gradients, shadows, blur, and vector paths. Idle windows use no CPU, and resizing stays smooth.</p>
		</div>
		<div class="elg-feature">
			<span class="elg-feature-icon"><Icon name="seti:rust" size="1.25rem" /></span>
			<h3>C++ and Rust</h3>
			<p>The same views and modifiers in both. C++ chains plain function calls; Rust adds `elg!`, a DSL that reads like the layout it builds. Every page here switches between them.</p>
		</div>
		<div class="elg-feature">
			<span class="elg-feature-icon"><Icon name="pencil" size="1.25rem" /></span>
			<h3>Hot reload and previews</h3>
			<p>Save a file and the running window shows the change a moment later. Previews put a single component on screen, in as many variations as you like.</p>
		</div>
		<div class="elg-feature">
			<span class="elg-feature-icon"><Icon name="star" size="1.25rem" /></span>
			<h3>Batteries included</h3>
			<p>Text editing, lazy lists, grids, menus, popovers, animation, themes, images, audio, video, the camera, file dialogs, notifications, and accessibility.</p>
		</div>
	</div>
</section>
