## Overview

<div class="elg-overview">
<div>

An interface in Elegance is made of views: text, images, shapes, controls, and the stacks and
grids that arrange them. Modifiers like `.padding()` and `.background()` refine a view, so how
it looks is written next to what it is.

State drives what's on screen. A closure that reads a piece of state runs again when the state
changes, and only the text, color, or frame that depends on it updates. Nothing is diffed and
nothing is rebuilt.

A WebGPU renderer draws everything, with anti-aliased shapes, gradients, shadows, blur, and
vector paths. Idle windows use no CPU.

The same views and modifiers are available in C++ and in Rust, where the `elg!` macro reads like
the layout it builds. Every sample in this documentation comes in both; choose one with the
**Language** switch at the top of the page.

</div>
<div>

```cpp
View Counter() {
    const State<int> count(0);

    return VStack({.spacing = 16},
        Text([=] { return std::format("{}", count()); })
            .font(Font::system(56, Weight::bold)),
        HStack(Button("−", [=] { count -= 1; }),
               Button("+", [=] { count += 1; })));
}
```
```rust
#[component]
fn Counter() -> impl IntoView {
    let mut count = State::new(0);

    elg! {
        VStack(spacing: 16) {
            Text("{count}").font(Font::system(56.0, .bold))
            HStack {
                Button("−", move || count -= 1)
                Button("+", move || count += 1)
            }
        }
    }
}
```
